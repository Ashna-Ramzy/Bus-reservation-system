# Bus-reservation-system

A console-based bus reservation system written in Java.

## Features
- Register customers and buses
- Search buses by route
- Reserve and cancel seats
- Waiting list and seat change requests

## How to run
1. Install Java (JDK 17 or later)
2. Compile: `javac BusReservationSystem.java`
3. Run: `java BusReservationSystem`
